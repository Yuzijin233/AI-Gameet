# image/ —— 头像放这里

界面上所有头像都读这个文件夹：`image/avatar_01.png` ~ `image/avatar_30.png`。

## 换成你自己的照片

**直接把同名文件覆盖掉就行**，不用改任何代码、也不用重启服务（刷新页面即可）。

- **尺寸、长宽比、形状都随意**：任意大小、任意比例的图都能用
- 显示时按**居中裁剪成正方形**，再用 CSS 裁成**圆形** ——
  所以竖图 / 横图 / 方图都没问题，人脸建议放在画面正中间
- 支持 `png` / `jpg`（jpg 请把扩展名改成 `.png` 也行 —— 浏览器按内容识别；
  想更保险就直接存成 png）
- 建议 **≥256×256**，太小的图放大后会糊
- 30 张可以只换其中几张，没换的继续用现在的占位图

## 这些占位图是哪来的

由 `tools/export-assets.ps1` 生成（`-Group avatars` 可以只重新生成头像组）：

```powershell
powershell -ExecutionPolicy Bypass -File tools\export-assets.ps1 -Group avatars
```

> 注意：重跑这个脚本会**覆盖** `image/` 里的 30 张图。换过真实头像之后就别再跑它了
> （或者跑之前先把 `image/` 备份一下）。

## 谁在用这些头像

| 场景 | 说明 |
|------|------|
| AI 对手 | 人设自带 `avatar` 字段（`src/data/personas.js`），指向这里的文件名 |
| 好友列表 / 房间座位 / 排行榜 / 结算页 | 同上 |
| 玩家自己 | **默认**用 `avatar_01`；在「点大厅左上角头像 → 我的形象」里**上传本地照片**，
会存成 data URL 直接覆盖默认头像（不上传就是这里的 `avatar_01.png`） |
