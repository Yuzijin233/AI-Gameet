# save/ —— 存档与 AI 记忆的本地文件

这个目录是**自动生成**的。游戏平时把存档存在浏览器的 localStorage 里，
每次存档时顺手往这里镜像一份，方便你**直接打开看 / 备份 / 手改**：

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `ddz_save.json` | 完整存档（缩进过的 JSON） | 备份、迁移到别的浏览器、手改数值 |
| `AI记忆.md` | 每个好友记住了什么（**给人读的**） | 直接双击打开看 |
| `AI记忆.json` | 只有记忆部分 | 搜索、对比（diff）、写脚本处理 |

## 怎么工作的

- 游戏每次存档（出牌结算、聊天、买东西…）都会 `POST /api/save` 把存档推给本地服务，
  服务端重新写这三个文件。**连着点很多下也不会反复写**，同一秒内的多次存档会合并成一次。
- 启动游戏时，如果这两个文件比浏览器里的存档**新**（例如你手改了 `ddz_save.json`，
  再刷新页面），或者浏览器里压根没有存档（换了浏览器 / 清了数据），游戏会用文件里的那份。
- 老存档（这个功能之前留下的、没有时间戳的那种）永远以浏览器里的为准，不会被文件冲掉。
- 所以：**想恢复进度 / 换台电脑，把这三个文件带走就行。**

## 手改的注意事项

- 改 `ddz_save.json`（它是完整存档）。改完保存，刷新游戏页面即可生效。
- 别改 `AI记忆.md` / `AI记忆.json` —— 它们是每次存档时**重新生成**的，改了会被覆盖。
- 想删掉某个 AI 的记忆：在 `ddz_save.json` 里找到 `friends` 里对应那条的 `memory` 数组，删掉那几行。
- 记忆文案长这样：`称呼：阿伟`（关于玩家）、`对局：低级场…`（每局自动写）、
  `自设：老家=杭州`（AI 自己顺口补的设定）。
