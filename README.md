# AI-Gameet · 社交-桌游平台（H5）

零依赖、零构建的原生 H5 棋牌桌（斗地主 / 小猫钓鱼 / 五子棋）。对手由 **DeepSeek（deepseek-flash，关闭思考模式）** 驱动，
每个 AI 有独立人设与台词；出牌由本地规则引擎保证合法，大模型只负责"说话"。

**AI-Gameet** 这个名字拆开看就是它的样子：**社交**（好友 / 群聊 / 友圈 / 好感度 / 记忆）＋ **桌游**（三种玩法）＋ **AI**（人设对手）。

---

## 开箱即玩（三步）

> 这里说的是**这个工作区（开发副本）**；发给别人的**绿色版**连 Node.js 都不用装，
> 见下面的「分发：绿色版」。

1. 解压整个文件夹（**别只拖出 start.bat**，`src/`、`assets/`、`music/` 都要在）。
2. 装一个 **Node.js**（<https://nodejs.org> 下载 LTS，一路下一步就行；没有 Node 时脚本会退回 Python）。
3. 双击 **`start.bat`** —— 浏览器会自动打开，游戏就能玩了。

> **AI 说话需要填一次 Key**：进入游戏后 **⚙️ 设置 → API Key**，把 `sk-` 开头的那串填进去
> （[platform.deepseek.com](https://platform.deepseek.com) 申请）。
> **不填也能玩**：所有 AI 会退回本地台词库，游戏功能一个不少，只是它不会"现场发挥"了。
> 安装包里**没有内置任何 Key**。

## 快速开始（开发用）

```bat
双击 start.bat
```

然后浏览器打开 **http://localhost:5173/**（启动脚本会自动拉起浏览器）。

- 优先用 Node.js 启动（只用内置模块，零 npm 依赖）；没有 Node 时回退 Python 静态服务。
- 端口 5173 被占用会自动 +1 并打印实际地址（URL 用的是**实际绑定的端口**，不会报错地址）。
- **只会有一份服务**：启动前先探一下有没有同一份服务已经在跑（`/__ddz` 身份牌），
  有就只把浏览器打开到你正在用的那个端口，然后自己退出 —— 所以**反复点 start.bat 不会攒出一堆终端，
  也不会把游戏打开好几遍**。要关掉服务，关掉那个一直开着的终端窗口即可（或 Ctrl+C）。
- 也可以直接 `node server.js`，或 `PORT=8080 node server.js`（Windows：`set PORT=8080&&node server.js`）。

> **启动脚本是纯英文的**：Windows 批处理只要包含中文（多字节字符），cmd 按行解析就会错位，
> 典型症状是"窗口一闪就退、服务没起来"。所以 `start.bat` 与服务器控制台保持纯 ASCII，
> 游戏界面本身仍然是全中文。
> 万一还是闪退：在该文件夹按住 `Shift` 右键 → 「在此处打开 PowerShell 窗口」→ 运行
> `node server.js`，就能看到完整报错。

不需要 `npm install`，不需要打包，改完源码刷新浏览器即可生效。

## 玩法与操作

大厅里有三个可玩游戏：**斗地主**（AI 人设对手 + 豆子结算）、**小猫钓鱼**（按鱼篓差距结算豆子）和 **五子棋**（15×15，无禁手，**不结算豆子**，只加好友好感度）。
大厅布局：**左上角是你的头像 / 昵称 / 身家 / 称号**，右上角是游戏 Logo；内容区**左侧「玩法与模式」，右侧「选择场次」**；
「玩法与模式」里还有 **发牌开关**（只对斗地主）：选「洗牌」= 每局把牌充分打乱（默认）；选「不洗牌」= 用原序新牌**只切几次、不彻底洗乱**——同花色和连续点数扎堆，更容易摸到顺子/连对/对子，牌型连、节奏快。小猫钓鱼每局固定洗牌，不显示这个开关。
底部导航：**👥 好友 / 商城 / 签到**；**称号入口在大厅左上角**（点头像旁的称号，未佩戴时是"未佩戴称号"占位），设置入口也在左上角（头像旁）。

### 斗地主

| 操作 | 方式 |
|------|------|
| 选牌 | 点击卡牌（上抬 12px）切换；**按住拖动可整段连选**，再次点击取消。**任何回合都能选**（别人出牌时可以先选好），只是没轮到你时不显示出牌按钮 |
| 出牌 | 点「出牌」或按 `空格` |
| 不出 | 点「不出」或按 `P`（首出不能不出） |
| 提示 | 点「提示」或按 `H`，连点循环切换不同组合 |
| 重选 | 点「重选」或按 `Esc` |
| 状态条 | **轮到你操作时状态条会描金边发光**（"轮到你出牌 / 叫地主 / 抢地主"，选好牌时也保持），一眼就知道该你了 |
| 聊天 / 语音 | 右下角输入框回车发送；😀 里是鲜花 / 番茄 / 鸡蛋 / 卡布奇诺与表情；🎤 点一下进入**持续语音输入** |
| 道具 | 鲜花 / 番茄 / 鸡蛋 / 卡布奇诺（商城买，每种每局最多 3 次），只表达情绪、不影响出牌 |

**AI 说话的两条规矩**：

- **叫地主 / 不叫都说话**：AI 每次叫抢地主都会表态（"这副牌可以试一手" / "牌不齐，我不叫"），不走概率
- **就牌论牌、绝不报牌**：AI 不会念自己的手牌（不会出现"4个2在手，不慌"），
  而是对着刚打出的那一手说（"对2，你还打得过？"）；说话提示词里根本不给具体手牌，生成后还会再过一道过滤

**AI 出牌 = 大模型决策（2026-06 改版）**：

- **AI 模式**下，出哪几张牌由**大模型**决定；提示词给全它自己的手牌、各家剩余张数、上一手、最近 5 手、身份、
  倍数和自己的**打法风格**（爱压 / 先走小牌 / 拆牌成顺 / 惜牌留大 / 抢着走完 / 稳健，按人设分配）——
  所以 24 个 AI 的牌风真的不一样。
- 模型只回**点数**（如 `5 5`、`10 J Q K A`、`小王 大王`），不出就回 `pass`；解析后还会做一次合法性校验。
- **15 秒预算、最多调用 2 次**：只有"15 秒还没出牌"或"连续两次调用失败"才回落到脚本机器人兜底。
- **机器模式**、以及玩家超时自动出牌，仍然走零延迟的脚本逻辑。
- **出牌和发言是两套独立逻辑**：先由大模型决定出牌，出牌之后再单独调一次模型生成台词。

AI 的气泡**按内容自适应、最宽 250px**（短句就一小条），说长了气泡自己变高、**里面不会出现滚动条**，停留 **4.2~4.4 秒**后消失。

### 斗地主的 AI 怎么出牌（纯规则引擎 + 牌技档位）

**出牌完全由本地规则引擎决定，大模型只负责说话**（用户拍板：模型打牌太蠢）。
引擎从合法牌型里挑，四档牌技各有参数，**最差也"勉强能玩"，强的很厉害**：

| 档位 | 前几名里随机 | 犯懒 | 记牌 | 认队友 | 报单压死 | 残局精算 | 思考时长 |
|------|------------|------|------|--------|----------|----------|----------|
| 新手 | 4 | 30% | ✗ | ✗ | ✗ | ✗ | 1.0~2.6s |
| 熟练 | 2 | 18% | ✗ | ✓ | ✓ | ✗ | 1.2~3.2s |
| 高手 | 1 | 5% | ✓ | ✓ | ✓ | ✓ | 1.6~4.0s |
| 大师 | 1 | 0% | ✓ | ✓ | ✓ | ✓ | 2.0~5.0s |

分数阶梯（实测 500 局/档，地主视角）：**新手 40.8% → 熟练 55.4% → 高手 66.4% → 大师 71.0%**。
30 位人设逐人分档（`src/data/ddzLevels.js`，注释写了理由）：不吃香菜 / 小柳先生 / Helloworld / 冷月 / 老张的茶 = 大师，
菜鸟萌新 / 菜就多练 / 本命是张卡片… = 新手。

底线（所有档位一致）：**手里能一把走完就无条件走完**、出的牌必须是手里有的、
**"能跟就跟"**（只有"只能靠炸弹才能压"时才按概率留炸）。引擎算得是瞬间的，
所以**故意等 1~5 秒**再出牌（`thinkDelay()`），桌上的"思考中"气泡也按真实时长显示 —— 不会再有"秒出"的穿帮。
AI 的台词照旧由模型按局势生成，**台词里不会露出"我在算牌/我用的是规则"**。

### 所有 AI 都知道"我们在一起玩 Gameet"

每条提示词的第一行都是同一句世界观（`src/data/style.js` 的 `GAME_WORLD_LINE`）：

> 你和玩家都在玩同一款叫「Gameet」的游戏 —— 一个**卡牌桌游 + 社交**的平台：里面有斗地主、小猫钓鱼、五子棋，
> 也有好友私聊、群聊和友圈。你自己也是这个平台的用户（有自己的号、开心豆和称号，会在友圈发动态、在群里闲聊、被朋友拉去开局），
> **不是站在旁边的 NPC**。这是背景知识：别主动解释这个平台、也别拿它当话题，更不要说"我是 AI / 系统 / 程序 / 机器人 / NPC"。

它挂在 `styleRules()` 的第一行，所以**私聊 / 群聊 / 房间弹幕 / 友圈 / 牌桌台词**全都拿到了。

### 开局：匹配界面（只在 AI 模式）

点场次的「开始游戏」后，先出现一个**匹配界面**：**并排三个座位（头像 + 昵称）**。

- **第 1 位默认就是你自己**（进界面时头像与昵称已经在了，金色描边）——
  头像走 `playerAvatarSrc()`：**你上传的照片会同步显示**（不是默认头像）- 另外两位先是虚线空心圈 + `?` + `匹配中…`，随着提示从 `正在匹配…` 走到 `已找到 1/3 → 2/3 → 3/3`，
  一个个把**头像与昵称填上**，每填一个"叮"一声，整段约 2.7 秒
- **点一下跳过**，不等完

刻意**没有**灰度到彩色的滤镜、没有头像缩放入场、没有任何 `@keyframes`/`transform` ——
状态变化只有"填满"这一种，看起来是安静地一个个就位，而不是在放动画；
也没有"有人取消了匹配"这种插曲。

房间模式已经在房间里等人了，不重复；**机器模式直接开局**（保持"安静快速"的定位）。

**进桌后 AI 认得出熟人（轻量连续记忆）**：随机匹配到**好友**会主动打招呼；
匹配到**上一局刚打过**的对手会提一句上一局（只认"上一局"，再早的局不提，免得记错又变慢）。
房间模式是你自己请的人，不演"偶遇"。
（好友那套完整的 memory / 好感度仍然只用在**私聊**里，不往牌桌上灌，避免 AI 负担太重、思考变慢。）

AI 每次说话都会看到**最近 5 步**：斗地主是最近 5 手出牌（含"不出"），小猫钓鱼是最近 5 步操作（翻出什么、收了几张、先不收）＋**双方手上剩余张数与鱼篓张数**（每条都标明"你（AI）"还是"对手（玩家）"，不会把两边搞混）。

**语音输入（🎤 持续收音模式）**：

- 点一下 🎤 → 进入收音状态，**可以一口气连着说几句**；按钮里会冒出 **4 根音量柱**跟着你的声音上下起伏
- **说完立刻发**（约 0.25 秒没人说话就发出去），直接进聊天、不落在输入框里、**不弹任何提示**；
  发完**仍然保持收音**，接着说下一句
- 屏幕下方"正在听…"的提示只闪 **3~5 秒**就消失，不会一直挡着
- 再点一下 🎤（或离开牌桌）才退出，退出时把没发出去的半句也发掉
- 用的是浏览器 Web Speech API（Chrome / Edge + localhost 可用）；不支持或被拒时提示改用文字，不影响其它功能

### 小猫钓鱼

点「翻牌」或按 `空格`；也可以打开**自动翻牌**只看结果。翻出的牌与中央同点数就会出现一次「钓」的机会：**收下**进鱼篓，或**先不收**留在中央攒更大的。

**左上角有记牌器**：13 个点数各显示牌堆里还剩几张（0 张变暗、只剩 1 张描金），悬停可看总数。

一局固定 52 次翻牌，最后按**双方鱼篓差距**结算豆子：五五开不输不赢，**越悬殊越陡峭**。

每局结束会弹出**独立的结算页**：胜负 / 鱼篓比分与差距 / 本局倍数 / 本局输赢金额 / 当前身家，
并提供 **加好友**（对手就是这一局的 AI，加完它会主动打个招呼）、**再来一局**、**返回主界面**
（返回时这一局已经结算完——加钱或扣钱都算数，中途刷新才算没打）。

| 场次 | 曲线 | 门槛 | 差 10 张 | 差 20 张 |
|------|------|------|----------|----------|
| 低级场 | 12d + 3d² | 1,000 | ±433 | ±1,483 |
| 中级场 | 低级 ×10 | 10,000 | ±4,326 | ±14,832 |
| 高级场 | 低级 ×15 且加三次方 | 100,000 | ±11,124 | ±59,328 |

赢/输系数 1.03 / 0.97，对称分布下解析期望 +28 / +284 / +1294 豆/局（只占单局波动 3%）。
参数在 `src/config.js` 的 `FISHING_ROOMS` 与 `FISHING`。AI 模式 / 机器模式同样可选。倍数：一次钓到 8 张以上本局倍数翻倍（封顶 ×8，见 `FISHING.bigCatchMin`）。

### 好友（AI 好友 + 好感度 + memory）

点底部「👥 好友」：左边好友清单（第二行是**第一人称个性签名**，比如"话不多，手不软"），右边聊天窗口（标题里显示关系档：点头之交 → 挚友 → 恋人）。点「添加好友」可以把牌桌上的任意 AI 加进来（**直接通过，不需要同意**）。

**会话列表 / 聊天窗口是照着真的聊天软件排的**（用户要求"看起来像真的在聊天"）：

| 位置 | 像真聊天的地方 |
|------|----------------|
| 左栏顶部 | **🔍 搜索框**：输入真的会筛左栏（按**名字 + 个性签名**匹配），找不到时给一句"没有找到这个人" |
| 会话行右侧 | **最后一条消息的时间**（今天给 `14:32`、昨天给 `昨天`、更早给 `3月5日`）+ **红色未读角标** |
| 我的消息 | 右边、**品牌玫红实心气泡**、每行都带**自己的头像** |
| 对方的消息 | 左边、白/灰白气泡 + 细线 + **一个小尖角**指向头像 |
| 连着说话 | **头像不重复画**、行距收紧，一眼看出"这是一串"（微信 / Telegram 的合并显示） |
| 时间 | 消息上方那一行**居中灰字**，只在"第一条"和"隔了 5 分钟"时出现 |
| 聊天标题 | 名字下面一行是**关系档 + 一个在线小绿点**（一直显示关系档；对方在打字也**不会**把这个状态换掉） |
| 正在输入 | TA 在想的时候，聊天框里出现一条**带头像的**「正在输入…」气泡（头像不会消失） |
| 输入条 | 灰白底 + 一根上细线 + 圆角灰槽输入框，发送键是品牌色胶囊 |
| 长回复 | 一句话太长时，TA 会**拆成两条消息**发（先发第一段，隔 1~2 秒再发第二段，中间照样显示"正在输入…"）；短句永远不会拆 |

- 每个好友**独立记忆**，按六类存：`称呼 / 偏好 / 约定 / 性格 / 身份 / 习惯`（写成「分类：内容」，如 `称呼：阿伟`），
  外加一类**系统自动写的「对局」**（见下）
- **好感度 0~100**，随聊天内容变化；界面上只显示关系称呼（点头之交 → 挚友 → **恋人**），**不暴露数值**
- **一起打一局也会加好感**：你**自己邀请**的好友（房间模式挑的人）**+3**，
  **随机匹配正好碰上**好友 **+1**；没加好友的对手不算。斗地主和小猫钓鱼都算，打完整局才加
- 每次对话都会**额外调用一次模型做判断**：这句话是加好感还是掉好感、要不要写进长期记忆
  （结果只落库、不提示玩家，玩家只会感觉对方态度在变、偶尔提起以前说过的事）

**恋人（好感满 + 明确表白 + 通过三条审查）**

- 好感度能刷到满 **100**。满 100 之后、而且你**还没有恋人**时，每次聊天会顺便审查一句：
  **你是不是在明确表白**（"我喜欢你""我们在一起吧""做我女朋友好吗"）
- **不让 AI 自由婉拒**：模型只负责判断"这句是不是表白"，**答不答应由系统按三条硬规则判**——

  | 条件 | 说明 |
  |------|------|
  | ① **必须异性** | 同性之间走不到那一步 |
  | ② **它必须单身** | 依据是"**之前聊过的内容**"里有没有涉及有对象（自设 / 记忆 / 它自己说过的话）；**从没提过就视为单身** |
  | ③ **它没有明确拒绝** | 回复里出现真实的拒绝理由（"我有喜欢的人了""我们不可能""只当朋友"）才算拒 |

  三条都过 → **同意**，关系从「挚友」变成「**恋人**」（名字后面挂 💞，**好友列表 / 私聊标题 / 房间座位 / 房间好友列表 / 牌桌座位**上都能看到）
- **傲娇人设单独判断**：她嘴上说"才、才不是呢""谁要跟你在一起，笨蛋"——这**不算拒绝**，照样判定为成功
  （只有她给出真实理由才算真拒）。人设标签里带「傲娇 / 嘴硬」的走这条
- **表白失败**：好感 **-10**（退回 90），并写一条"婉拒过"的记忆；
  **想再表白就要重新把好感刷满 100**（聊天 / 送礼 / 一起打牌都能刷）
- **全局只能有 1 个恋人**：已经有恋人了就**不再触发表白审查**（跟别人表白只会当普通聊天）
- 成为恋人之后，审查的内容换成**你是不是在明确提出分手**（"我们分手吧""还是做朋友吧"）；
  分了 → 关系掉回「朋友」（好感度落到 60）。闹脾气和假设句（"你再不理我就分手"）不算

**自设（AI 自己顺口编的设定，不会前后矛盾）**

人设里没写"老家在哪""什么职业"，你一问它就会顺口编一个。为了不让它下次编成另一个：

- 审查的同一次调用里会让它把**这次新说的、人设里没有的设定**写成 `{"老家":"杭州"}` 这种形式
- 存成 `自设：老家=杭州`，**按"方面"覆盖** —— 同一个小方面永远只有一条，不会"既是杭州又是成都"
- 这些自设会进**下一次的提示词**，标注「你自己在聊天里说过的设定（必须保持一致）」
- **不会记反**：写入前还有一道**硬校验** —— 自设必须出自**它自己那句话**、玩家记忆必须出自**你那句话**。
  比如你说「我是南京人」、它答「我是溧阳的」，即使模型把两边写反了也会被拦下来，不会存进记忆
  （模型合理改写的说法一律保留，只在能证明"记到对方头上"时才丢）
- 群聊里也一样：谁顺口补充的设定就记在**谁**名下
- **对局记忆**：每打完一局（正常结算才算），把这局浓缩成 **50~100 字**概括写进**参战双方**的记忆，
  只保留**最近 3 局**。下次聊天它真的记得"上次那局你被两个炸弹炸到 ×16"，而不是笼统地说"刚打完一局"
  - **没和你一起打的好友不会拿到这条记忆**：它只能"听说/问问"，提示词里明确写了"你不在场"，不许假装参加
  - 提示词里带上玩法名，所以**小猫钓鱼的局不会被说成斗地主**
  - 刚把某个 AI 加为好友时，会把最近 3 局里它陪过你的局**回填**进记忆（"它其实早就记得你"）
- **30 个人说话不像同一个人**：部分人设爱发表情（😪😤😂）、部分**偶尔**用颜文字，
  话痨会说 2~3 句（最长 50 多字），也有人惜字如金；线上提示词与**离线本地台词**同一套风格

**颜文字口径（用户拍板，2026 版）**：

- 每个人设的颜文字**池子是 3~6 个**，代码**随机挑一个**（不再永远用同一个）

### 聊天时间背景（防止 AI 时间错位）

```
距上次说话：12 小时前（上次是 9月23日 23:10）。
注意：上次说话是「另一天」（9月23日 23:10），而现在是 9月24日 11:05（上午）。
昨晚的对话已经过去一夜了，别再接着那个时间点的场景说话 ——
比如昨晚聊到"还不睡"，今天白天就不要再问"怎么还没睡"，可以自然地说"早啊""昨晚睡得怎么样"。
```

给模型看的**历史对话也按天打了小标**：跨天的那一条前面挂 `（9月23日 23:10）`，
回到今天的挂 `（今天）`，同一天内的不重复挂 —— 它一眼就能看出"这些是昨天说的"。

牌桌台词用简短版（只给时间 + 一句提醒），避免每次出牌都白烧 token。
同时都写明了：**这是背景知识，不要主动报时间、也不要每句都提**。

### 群聊（好友面板的第二个标签）

「好友」面板顶部有两个标签：**👤 好友 / 👥 群聊**。切过去就是群聊界面（不是一上一下摞着）。

- **创建群聊**：填群名称（不填随机一个）+ 勾好友；**只能拉已经是好友的人**
  （至少 2 位、最多 10 位，最多建 5 个群）。建好后会有 1~2 个人主动打个招呼
- **点群名改名**；右上角「邀请好友」拉人、「解散」删群；成员头像悬停出现 ✕ 可以移出
- **发言之后谁来回**：
  1. **点名必回** —— `@冷面棋手` 或直接写名字，点到的人一定回答
  2. **点某条消息 = 回复它** —— 点一下 AI 消息，输入框上方出现「正在回复 XX」，发出去之后
     **那个人一定会回你**，消息里也会带上引用
  3. 其余交给 **AI 判断该谁接**（把群成员名单 + **最近 10 条群消息** + 你这句交给模型挑人），
     挑不出来时用本地兜底（标签命中 + 好感度 + 话痨加分）
  4. **几个人回**：1 人群 1 个；3 人群 1~2 个；5 人群 2~3 个；8 人以上 2~4 个（最多 4 个）
  5. **一条条回**：每条之前先显示「XX 正在输入…」，两条之间**随机等 2~3 秒** ——
     像真人在群里一条条回，不是一次性刷出来
- **群聊不影响好感度**（三个文件里都没有改好感度的调用，测试逐文件锁死），
  但群里聊到的内容**仍会过一遍 AI 审查**，决定要不要写进各自的长期记忆
  （"我叫阿伟"→`称呼：阿伟`）；审查只认在场的人，不在场的不会被写
- **挂机时 AI 会自己聊起来**（用户拍板）：你停在群聊界面**静默 10 秒**、且群里 AI **多于 2 人**（≥3）时，
  它们就自己接话 —— 每 **8~20 秒**随机一个人发一句（第一版是 5~15 秒，用户反馈"太快了"，已放慢），
  看得到上下文、也带着各自的记忆；
  **话题不必和你有关**，下一句由 AI 判断该谁接（不会挑刚说过话的那位），所以聊得下去、不会自言自语；
  你一发话立刻停，之后再静默 10 秒才重新开始。
  （挂机闲聊**不写长期记忆** —— 那是你和它对话时才沉淀的东西；它们用的仍是已有的记忆）

### 房间弹幕

**弹幕只在房间（等人开局）界面里飘**，牌桌上 AI 说话还是头顶气泡。

**记忆与好感度和私聊是同一份，而且弹幕只读不写**：

- **读得到**：弹幕提示词里带着**和私聊完全一样**的东西：好感度多少、什么关系、
  **平时怎么称呼你**、记得你什么事、它自己说过的设定、以及恋人关系 ——
  所以关系越好房间里越随便，生分就冷淡一点，是恋人会在房间里护着你
- **不写**：房间弹幕**不写记忆、不写自设、也不动好感度**。
  要不要沉淀只由**私聊**决定 —— 方向是单向的：**私聊聊过的房间看得到**，
  反过来房间里的闲聊不会污染记忆和好感度
- **能读到前面几条弹幕**：按从早到晚列出最近 6 条，每条都带说话人（`名字：内容`），
  还会提醒它"最后一条如果是你自己说的就换句说法"

### 牌桌 / 钓鱼台上也知道你和它的关系

斗地主台词和小猫钓鱼的发言同样带着这层背景（好感度、关系档、称呼、记忆、恋人），
所以关系不同说话口气也不同 —— 挚友可以随便损你，生分的不会自来熟，恋人会护着你。
**这些都是背景知识**：提示词里明确要求不要报好感度、不要拿关系当话题。

### AI 自己的豆子与称号（所有场景都实时注入）

**每个 AI 都知道自己现在有多少开心豆、戴着什么称号**，这一行由
`aiEconomyLine(beans, title)` 统一生成（`你自己的身家：💰233,491（戴着称号「富甲一方」）`），
**私聊 / 群聊 / 房间弹幕 / 友圈评论**四个场景共用同一份口径：

- **实时现算**：每次生成台词前都从存档里现读一次，AI 的豆子被加减、或者称号档位变了
  （称号跟着身家自动走），**下一句就是新的**，不会停在旧数据上
- 提示词里写明了：**别刻意提钱、也别拿称号当话题**，聊到了（比如约局、说输赢）可以自然带一句
- 房间里玩家自己的称号仍然单独注入（`playerTitle`），两边不会混

### 房间模式

**被 AI 邀请进游戏时**（画面上方那张邀请卡）：

- 卡上的**勾 / 叉是用 CSS 画出来的两段线**（不再用那两个符号字形 —— 各家系统字体把它们渲染得又粗又怪，用户点名要"正常字体"）
- 你点接受、真的开局之后，**邀请你的那位（房主）会主动说一句**：大意是"总算把你拉来了"，
  由模型按它自己的身份与说话风格生成（提示词里写死**不许提系统 / 规则 / AI / 模型**）；中途退出就不说了
- 三种玩法都会说（斗地主用气泡，小猫钓鱼 / 五子棋走各自的台词通道）

**五子棋**：棋盘上那颗**刚下的棋子**会有一圈金色描边（玩家和对手都适用）。
以前这个记号是错的 —— 它取的是 DOM 里最后一个元素，而棋子是按 y/x 扫描顺序塞进去的，
所以高亮经常跑到"最靠右下角的那颗"上（用户报的"有时候看不到对手刚下哪里"就是这个）。
现在改成从 history 里取真正的最后一手。

「玩法与模式」里选 **房间模式** → 点场次的「开始游戏」→ 弹出的房间里：

- **左侧是常驻好友列表**（头像 / 昵称 / 称号 / 身家 / 关系），**点一下好友就入座**，再点一下移出；座位卡上的「踢出」同样能移除
- 座位卡两行：昵称一行，**第二行是「称号 + 房主 / 点头之交 · 身家」**（关系与身家就贴在称号右边，身家压缩成 `1.2万`，不占地方）
- **人满才能开始**（斗地主 2 位、小猫钓鱼 1 位）；身家不够门槛的好友也能邀请，座位会标「补足入场」
- 开局后对手就是你邀请的好友：人设、说话风格、memory、**身家（全局共享）**全部沿用

**房间弹幕**：弹幕**只出现在房间（等人开局）界面**，牌桌上一律是气泡；在房间里对手用**弹幕**交流（从右往左飘）：

- 每 **3~5 秒**一条；**两个 AI 会互相接话**，也会跟你的弹幕聊（提示词里带上最近几条弹幕及说话人）
- **进房后你 5 秒不说话，AI 会先开口**（这时只有 1 个好友它也会开口，房间不会冷场）
- **你发一条弹幕，AI 要"打字" 3~5 秒才回**（模拟真人，不秒回）
- 场景是"人还没齐、牌还没发"，所以聊的是约战、放狠话、损人，不掺牌桌上的术语
- **每人一种颜色**：你=金色、第一位好友=粉色、第二位好友=蓝色，弹幕前带名字，一眼看清谁在说
- **房间里只有 1 个好友时（小猫钓鱼房间）**：平时它不主动发，你发一条它才回（**进房 5 秒你还没说话时，它会先开口一次**）
- 你自己也能发：房间面板底部的输入框，发言会以弹幕形式出现
- 弹幕的说话人 = **你邀请进房的好友**（按邀请顺序），踢出会同步更新
- AI 在房间里**看得见你的称号和昵称**（当背景知识，话题还是围绕人和游戏，不会围着称号聊）
- **人数也是背景知识**：提示词里会告诉 AI"现在几个人、这局需要几个人、还缺几个"，
  所以斗地主房里只有你和 1 个好友时，它会自然说"二缺一"

### AI 身家（全局、跨局变化）

24 个 AI 每人有一份**全局身家**存在存档里，跨局、跨场次、跨模式共享：

- **初始分配**：每人 `1,000 ~ 2,000,000`，按**幂律偏小**随机（小身家的 AI 多，富豪少）
- **每局正常打完**（中途退出本局作废，AI 身家一分不动）：
  - **参战的两个 AI** 按本局结算增减（输光即止，不会为负）
  - **其他 AI** 按当前身家浮动：涨 `+0~20%` 或 跌 `-0~10%`（各 50%）
  - 浮动后身家仍低于 `1,000` 的 AI 领**低保** `5,000`（每个 AI 每日一次）
- **称号跟着身家走**：AI 自动佩戴对应的身家档称号（穷光蛋 → 富可敌国），房间座位与好友列表里都能看到
- **抽对手只看门槛**：点某场次开始时，只从身家够这个场次的 AI 里随机抽
  （低级 ≥1,000 / 中级 ≥10,000 / 高级 ≥100,000）
- **极端兜底**：万一中级场或高级场**一个能打的 AI 都没有**，会随机给**你好友以外**的 AI 输血：
  3 个改成 `10,000~100,000`（够中级场）、3 个改成 `100,000~2,000,000`（够高级场）
- **好友私聊时 AI 知道自己的身家与称号**（当背景知识，聊到输赢、约局时可以自然带一句，不会刻意提钱）

### 商城与道具

底部「商城」分四类：

| 分类 | 内容 |
|------|------|
| 💰 开心豆 | 模拟充值套餐（¥6 / ¥30 / ¥108 / ¥498，1 元 = 1,000 豆） |
| 🏅 称号 | 花开心豆买，**只展示还没拥有的**；买到的去左上角称号面板佩戴 |
| 🎁 道具 | 🌸 鲜花 / 🍅 番茄 / 🥚 鸡蛋（各 💰500）、☕ 卡布奇诺（💰2000）—— 牌桌上用 |
| 💝 礼物 | 🌹 玫瑰花 💰1,000（好感 +1）/ 🎁 礼盒 💰9,999（+3）/ 💎 钻石 💰88,888（+10）/ 💍 戒指 💰520,000（+30）—— **好友界面**送 |

道具在牌桌上用（右下角 😀 里的道具行），**只表达情绪、不影响出牌**：
可用次数 = `min(库存, 每局 3 次 - 本局已用)`，库存为 0 时提示去商城买。新手礼包各送几个。

**礼物**和道具是两套东西（库存共用 `save.items`，用途完全不同）：

- 在**好友界面**点头像旁的「🎁 赠送礼物」送出，**每位好友每天最多 3 次**（用户拍板）
- 好感度按档位加（+1 / +3 / +10 / +30），并写一条**独立的「礼物」记忆**：
  `礼物：玩家送过我 🌹玫瑰花×2、💎钻石×1`（同类累加件数，不会越堆越多）
- 送出去会**发一条赠礼消息**（聊天里渲染成带金边的礼物卡），好友**据此回应** ——
  提示词里明确要求"先谢他"：关系生分就客气道谢，关系亲密可以随便一点甚至调侃他破费
- **AI 也会回赠**：审查那一次调用多判一层"这次要不要送点什么"（见「AI 配置」一节），
  受**它自己的身家**与**关系档位**双重约束（关系不到位送不了贵的，穷的时候只送得起玫瑰），
  **每天同样最多 3 次**；它送的东西**进你的道具库存**（牌桌上能当道具用），钱从它身家里扣

### 称号

三个来源，拿到就永久拥有，随时佩戴或卸下：

- **按身家自动解锁**：穷光蛋 → 小赌怡情 → 手气不错 → 豆子大户 → 一掷千金 → 富可敌国
- **连续签到 8 天**赠送「**劳模**」（断签只重算进度，已拿到的不收回）
- **商城花豆购买**：牌桌萌新 / 常胜将军 / 桌上一霸 / 斗地主之王 / 熬夜冠军 / 手气爆棚 / 一掷万金

入口在**大厅左上角**（点头像旁的称号，没佩戴时显示"未佩戴称号"占位）；称号面板分「按身家自动解锁 / 连续签到赠送 / 商城称号」三组，
只展示已拥有的商城称号（没买的去商城的「🏅 称号」分类），签到档未获得时会显示进度（如"连续签到 3/8 天"）。

规则要点（完整边界见 `PRD_斗地主AI游戏.md` §5）：
**抢地主制**（叫地主 1 倍 → 抢 ×2 → 反抢 ×2，最多 3 次，全不叫则重发）；
倍数 = `2^(抢+反抢) × 2^(炸弹+王炸) × 春天系数`；
结算 `单笔 = min(底分 × 倍数, 场次封顶豆, 付款方身家)`，**输光即止、永不为负**。

| 场次 | 底分 | 封顶（每笔） | 入场门槛 |
|------|------|--------------|----------|
| 低级场 | 10 | 256 豆 | 1,000 |
| 中级场 | 100 | 8,192 豆 | 10,000 |
| 高级场 | 2,000 | 100,000 豆 | 100,000 |

豆子来源：**新手一次性 20,000**（够在低级场久留）、每日签到（7 天循环，连续 8 天送「劳模」称号）、
身家低于 1,000 时的每日救济金 5,000、以及商城模拟充值（1 元 = 1,000 豆）。

## AI 配置

`src/config.js`：

```js
model: 'deepseek-flash',   // 默认模型
thinking: false,           // 关闭思考模式（开启会先输出思维链，拖慢出牌节奏）
apiKey: 'sk-...',          // 当前写死；后续可换成代理
useProxy: false,           // 浏览器直连被 CORS 拦时改 true，走本地 /api/chat 代理
```

- 提示词严格遵守信息边界：**AI 只能看到自己的手牌 + 公开信息**（各家剩余张数、已出牌、倍数），看不到别人的手牌（PRD Q17）。
- **发言频率按牌型分档**（"说不说"由脚本掷骰子决定，"说什么"由牌型决定，见 PRD §2.8.1）：
  | 场合 | 概率 | 谁开口 |
  |------|------|--------|
  | 叫 / 不叫地主 | 100% | 出价的那位 |
  | **炸弹 / 王炸** | 100% | **桌上每个 AI 各一句** |
  | **春天 / 被反杀（反春）** | 100% | **桌上每个 AI 各一句** |
  | 长牌型（连对 / 长顺子 / 飞机 / 四带二） | 100% | 出牌的那位 |
  | 普通牌（单张 / 对子 / 三带一…） | **50%** | 出牌的那位 |
  | 过牌 | 25% | 过牌的那位 |
  | 玩家发言 | 100% | 必有一位接话 | 
  - **50% 那条路省调用**：脚本先掷骰子，**掷中了才真的向大模型发请求**，没中直接闭嘴
  - **大事件按身份换口吻**：出炸弹时 A 和 B 都要说，`self` 得意 / `mate`（同是农民）替他叫好 / `foe` 惊讶有压力；
    两位 AI 错开 900ms 开口（同时弹两条气泡太假），且都带 priority 绕过全局间隔
- **优先说与局势匹配的话**：地主快走完、搭档剩一张、自己快赢、倍数很高、被你的大牌压住等（`src/ai/lines.js`）。
  你打出大牌 / 好牌时对手会立刻有反应；大事件会把"发生了什么、你该什么态度"单独写进提示词。
- **开局匹配界面（只在 AI 模式）**：全屏一行字 `正在匹配… → 已找到 1/3 → 2/3 → 3/3`，每报一个数"叮"一声，
  点一下跳过；**不画动画、不放头像图片**，也没有"有人取消了匹配"这种插曲（PRD §2.15）。
- **牌桌上的连续记忆（轻量版）**：AI 模式随机匹配到**好友**会主动打招呼，
  匹配到**上一局刚打过**的对手会提一句上一局；房间模式不演"偶遇"（PRD §2.16）。
- 节流：同一 AI 间隔 ≥2s（必说的场合 0.6s）、任意两个 AI 之间 ≥7s（关键局势与出牌可插队），
  单次请求超时 8s（走代理 12s）、重试 1 次，连续 3 次失败才判定离线并降级到本地台词库——**断网也能正常玩**。
- **不设每局发言条数上限**（测试里只有 200 句/局的防跑飞兜底，不是产品限制）。
- 设置面板里可以改模型名、切换思考模式、测试 Key 连通性。

## 分发：绿色版（**对方不用装任何东西**）

```bat
node tools\pack-green.mjs 1.5      :: → AI-Gameet_绿色版_v1.5.zip
node tools\test-green.mjs          :: 打包 → PowerShell 解压 → 起服务 → HTTP 探一遍 → 跑产物
```

绿色版是给"只想双击就玩"的人的：**不用 Node.js、不用 Python、不用联网装依赖**，
本地服务由 Windows 自带的 **PowerShell（HttpListener）** 提供 —— 见 `serve.ps1`：

- 静态文件 + 音频 **Range**（BGM 拖动不弹"下载"）、`/api/chat` 转发 DeepSeek、
  `/api/save` 存档镜像、`/api/memory` 记忆清单、`GET /api/save` 恢复
- **localhost 是安全上下文**，所以语音输入（麦克风）也能用 —— 这也是为什么不做"双击 index.html"的纯静态版
- 端口 **5176**（被占用就往后找 5176-5185），已在跑的同一份服务会被认出并复用，不会开出第二个

包里的文件就 9 项，**看不到 `src/`、`server.js`、`tools/`、`styles/`**：

| 内容 | 说明 |
|------|------|
| `index.html` | 13 个 `styles/*.css` **已内联**（`../assets` 路径同步改写成 `assets`），只剩一个 `<script defer src="game.js">` |
| `game.js` | 75 个 ES 模块打成的**单个经典脚本**（`tools/bundle.mjs`），模块 id 换成 `m0/m1…`，源码目录结构不外泄 |
| `assets/` `image/` `music/` | 贴图 / 头像 / BGM 原样 |
| `start.bat` `serve.ps1` `README.md` | 启动器（纯 ASCII + CRLF）、本地服务（纯 ASCII）、**写给玩家看的中文说明** |
| `save/README.md` | 存档目录，**包里不带任何存档**：每台机器全新开局 |

另外：`src/config.js` 的 **apiKey 在打包产物里清空**（工作区原文件不动）；
不做加密 —— 浏览器必须拿到明文才能跑，加密只是"看着麻烦"，绿色版干脆不装
（真想抄的人 DevTools 里照样看得见，这一点没打算骗自己）。

## 已知边界（有意为之，见 PRD §8）

- 退出 / 刷新 = 本局作废、不结算（`CONFIG.exitRule = 'void'`，测试期策略，改成 `'lose'` 即按认输结算）。
  **AI 身家也遵守这条**：只有正常打完的局才会让 AI 身家变化。
- 不做防作弊、不做内容审查、不做账号体系；存档在 localStorage，清缓存即归零。
- 页面按 H5 写，验收基线是桌面 Chrome / Edge（≥1280×720），移动端不承诺。
