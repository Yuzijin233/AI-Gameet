# music/ —— 背景音乐

放两个 mp3 文件在这里就行（文件名**必须**是这两个，改文件名要改 `src/ui/audio.js` 的 `fileFor()`）：

| 文件名 | 什么时候响 |
| --- | --- |
| `battle.mp3` | **对局里**：斗地主 / 小猫钓鱼 / 五子棋 都用它 |
| `background.mp3` | **其他所有场景**：加载页、大厅、商城、活动、社交…（进对局自动切走，回大厅自动切回来） |

- 音量：游戏里 **⚙️ 设置 → BGM 音量** 那根滑杆（同时管这两条）；`音效音量` 管出牌/炸弹/到账这些短音效。
- 两条都是**循环播放**的，长度随意。
- 两个文件**没放也不会出问题**：会自动退回游戏自带的那套合成 BGM（不会变哑巴）。
- 放进文件后**刷新页面**就生效（浏览器会缓存，换歌记得强刷 Ctrl+F5）。
